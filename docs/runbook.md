# Public Showcase Maintenance Runbook

When updating this case study:

1. Keep client identity and commercial details out of the repository.
2. Do not copy source code, workflow definitions, binaries, logs, or private screenshots from the engineering repository.
3. Add only evidence-backed capabilities and outcomes.
4. Keep automated regression, packaging smoke, and live target-environment acceptance clearly separated.
5. Run the disclosure-boundary workflow before treating a change as publishable.
6. If disclosure status becomes uncertain, keep the material private until reviewed.
